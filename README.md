# XPS Virtual Lab

Laboratório virtual de espectroscopia de fotoelétrons excitados por raios X (XPS).

**Versão:** 1.0-rc2 — candidata à versão estável.

## Autoria
Prof. Dr. Renato Dutra Pereira Filho — Universidade Federal do Rio Grande (FURG), Escola de Química e Alimentos (EQA), LAcOPQ, Engenharia Química. Rio Grande, Brasil, 2026.

## Objetivo
Apoiar o ensino e a preparação de pesquisadores para interpretação de espectros XPS. Desenvolvimento incremental com programação assistida por IA e supervisão científica do autor.

## Execução
Abra `index.html` em um navegador moderno. Não exige instalação nem conexão para as funções locais. Links externos exigem internet. Para publicar no GitHub Pages, selecione a raiz da branch principal nas configurações Pages.

## Recursos
Fundamentos, aquisição simulada, quantificação, desafios, referências, ajuste de picos (Gauss, Lorentz, pseudo-Voigt e Voigt), fundos linear, Shirley e Tougaard, biblioteca química, importação de dados tabulares, profundidade/ARXPS, amostras desconhecidas, instrumento virtual, validação numérica e autoria.

## Validação e limitações
Execute os testes na aba Validação. A validação experimental com espectros reais, testes completos de interface e leitores de tela permanecem pendentes. Não substitui software certificado, calibração ou treinamento operacional. VAMAS nativo, linhas Auger e estatística poissoniana completa ainda não estão implementados.

## Histórico
